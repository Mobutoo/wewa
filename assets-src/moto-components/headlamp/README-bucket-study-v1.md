# Godet PF401007 voisin — étude retenue hors candidat

Étude grise initiale construite après plan G2, sans rendu, sur les photographies du PF401007 voisin. La recherche indépendante a ensuite fourni quatre photographies DY401002 : deux arceaux et pourtour sombre plus proches de la référence officielle RDC, dos/supports différents. Aucun code voisin n’est certifié RDC.

Cette étude non placée reste un diagnostic de variante ; aucune finale, export moteur validé ou inscription de production n’est demandée. Ne pas la présenter comme le phare actuel. Les surfaces, épaisseurs, ouvertures et supports étaient des estimations, les sièges de vis et nervures intérieures inconnus. La suite reprend G1/G2 sur le nouveau dossier avant fabrication.
