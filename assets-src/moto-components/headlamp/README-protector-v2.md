# Protection extérieure du phare — candidat v2

Pièce isolée originale WEWA : entourage sombre et deux arceaux devant l’optique. La disposition est visible sur les images officielles RDC125HD ; quatre vraies photos DY401002 CT110X/CT125X liées montrent les barres séparées du verre. Elles n’établissent ni code exactRDC, ni démontabilité ni compatibilité du dos. Aucun godet DY ou PF voisin n’est intégré à ce candidat.

Le diamètre, la section, le cintrage et l’avance des barres sont estimés. Aucun placement sur le cockpit, fixation arrière ou jeu réel avec lentille/cowl n’est établi. La collection `WEWA_HEADLAMP_FRONT_PROTECTOR` est à l’origine isolée, avec racine `HEADLAMP_PROTECTOR_ISOLATED_ORIGIN_UNPLACED`, sans commande mobile. Le lot12 est incomplet.

La matière est un revêtement sombre propre original estimé, sans photographie, grain non mesuré ni usure inventée. Le gris v3 précédent est gelé ; ses normales sont dérivées des profils et rattachées aux véritables identifiants de volumes CSG, sans pondération globale. Les attributs de forme/normales/UV et indices du GLB sont réellement identiques entre le gris v3 et ce candidat matériel.

Voir `creative/reviews/headlamp-front-protector-v2/` pour les contrôles et vues réellement exécutés ; un contrôle automatique n’est pas une réception artistique ni une qualification Safari physique.

La v2 neutralise uniquement la couleur de la première matière après ouverture réelle des quatre aperçus v1 ; la première proposition bleutée reste diagnostique. Le noir neutre est un choix de travail, sans teinte physique mesurée.
