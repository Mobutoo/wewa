# Bande formée du collier DP101198 lié — isolée

Deux fichiers Crosland du code exact ont été réellement ouverts ; ils montrent la même pose. La bande est lisse, avec deux oreilles pliées et percées. La vis tangentielle, les portées/écrous et le pont intérieur chevauchant sont des pièces observées distinctes, encore à fabriquer après cette bande. La section cachée reste estimée.

Le diamètre intérieur45mm et la largeur10mm sont des choix de travail inspirés de la description commerciale liée ID45 X W10 ; ils ne sont pas promus en cote constructeur ni RDC. Le conflit de recherche39mm reste ouvert. Épaisseur0,6mm, retour4mm, oreilles/perçages et ouverture60° sont estimés. BandeID45 et manchonOD45,6mm estimé présentent0,6mm d’interférence diamétrale en rigide : aucune compression ni installation reçue.

Repère isoléXY, axe de largeurZ, fermeture−Y, futur axe de visX. La source conserve sections et retours ; aucune déformation de la pièce voisine pour forcer le montage. La matière jaune irisée photographiée ne prouve pas sa chimie. Les textures photographiques restent privées.

G4 : une carte couleur originale1024² propose de faibles variations jaunes/vertes. Aucun pixel photographique, grain ou iridescence angulaire n’est utilisé. Le témoin uniforme et le candidat ont été comparés avec le même cadrage24spp : différence faible dans la vue entière, variation olive/jaune discrète dans les macros. Cette proposition ne reçoit ni la finition ni sa chimie.

Un atlas UV a été créé explicitement après le gris b67a : positions, topologie, normales de coins et matrices source sont identiques ; l’exporteur réindexe néanmoins les sommets. Entre le témoin uniforme doté de cet atlas et le candidat avec carte, les vrais buffers POSITION/NORMAL/UV/index et les matrices sont bit à bit identiques. La carte embarquée a été décodée et ses pixels comparés à l’original. À1024px,14038 petits triangles de biseau n’ont pas de centre de pixel ; leur UV n’est pas effondré, le remplissage utilise la couleur de surface proche. L’échelle du motif3–9mm est estimée.
