# Soufflet de fourche — candidat isolé v1

Le composant MOTO-FORK-BELLOWS-001 est une paroi continue originale, ouverte aux deux extrémités. Six couronnes arrondies et les deux manchettes suivent l’apparence des photographies officielles RDC125HD. Le nombre est inféré, avec une incertitude d’une couronne : les extrémités photographiées sont partiellement cachées. Aucune cote de ce soufflet n’est publiée dans les sources consultées.

Longueur125mm(plage100–160), diamètre des couronnes52mm(plage46–62), paroi des plis0,8mm(plage0,6–1,4) et manchettes2,2mm(plage1,4–3,2) sont des **estimations de travail**. L’interface du futur fourreau reste à vérifier.

La collection à lier est WEWA_FORK_BELLOWS_ISOLATED. Son axe est+Z, son origine le centre de l’ouverture inférieure. Aucune pose de montage n’est appliquée. La source Blender contient397échantillons par méridienne,192secteurs, une paroi intérieure décalée suivant la normale et deux clés de forme. Les variantes110/140mm montrent une compression/extension **visuelle estimée** ; elles ne représentent ni la course certifiée, ni une simulation de déformation ou d’incompressibilité du caoutchouc. Utiliser exclusivement la compression sous125mm et exclusivement l’extension au-dessus. Aucun amortissement mécanique n’est revendiqué.

Les cartes normales et rugosité/métal512² sont originales et périodiques. Le relief RMS1,27µm, sa force0,55 et la rugosité0,42–0,59 sont des choix de rendu estimés. Les14répétitions autour de la pièce donnent une période physique variable d’environ7,09–11,67mm ; l’arc méridien de base utilise10mm, les lèvres une projection plane10mm. Les UV restent fixés à la base pendant les morphs, ce qui étire cette matière estimée. Aucun pixel documentaire n’est incorporé. Le noir non métallique ne certifie ni une formulation ni une réflectance mesurée.

Le convertisseur Blender4.3.2 applique nativement la rotation inverse au transport des tangentes morphs. Le helper local gltf_morph_tangent_compat.py corrige le sens base→cible uniquement pendant cet export et restaure la méthode dans finally. Il refuse une version ou empreinte native différente. Ni l’installation partagée ni les buffers GLB ne sont modifiés. Le code dérivé conserve sa licence Apache2.0 distincte. Ce transport par normale n’est pas un recalcul complet MikkTSpace pour chaque cible. Les cinq états contrôlés incluent les poids intermédiaires ; le signe w natif reste conservé.

Les contrôles des vrais buffers vérifient les positions, normales, tangentes, UV, volumes, ouvertures et deux cibles. La matière laisse tous ces buffers identiques à la géométrie grise corrigée. Les vues finales sont des rendus Blender réels ; les contrôles du moteur, de l’assemblage et des LOD mobiles restent séparés. Ce candidat n’est pas une pièce reçue par l’utilisateur.
