# Selle WEWA — enveloppe extérieure candidate v1

La coque de housse à sections variables, son bourrelet arrière et102points de couture estimés sont séparés. Les deux premières études grises ont précédé les détails ; les diagnostics de pincement et de courbe du bourrelet restent conservés. Le corps gris2 reste intégralement inchangé. Le dessous reste ouvert : mousse, embase, nervures, appuis et montages ne sont pas représentés comme un intérieurOEM inventé.

Le vinyle noir, les microreliefs procéduraux et WEWA sont originaux. Les PNG sont embarqués et relatifs, sans pixel des photos documentaires. La petite inscription arrière remplace BOXER ; son sens a été vérifié dans les vrais aperçus. La housse JV191001 liée est embossée, mais la résolution des vues courantes ne tranche pas ce détail : la proposition lisse ne prouve pas l’absence de lignes sur la selle RDC.

La recette s’exécute dans cet ordre : générateur d’images original après revue grise4, build_candidate_v1.py sous Blender4.3.2, puis orthogonalize_export_tangents_v1.py et contrôles Node. Ce dernier projette seulementTxyz sur les normales stockées, avec les signes conservés et tous les autres octets binaires inchangés ; le rapport quantifie cette petite correction de transport, sans revendiquer une base Mikk bit-identique ni une parité visuelle source/export.

Dimensions, profondeur/sections, rayon du bourrelet, pas des fils, grain/teinte et identité exacteRDC restent estimés. Aucune réception artistique, montage ou validation iPhone n’est déduite de cette fabrication extérieure.

Quatre aperçus studio12 et un appoint sous ciel neutre, avec vraie carte diffuse18%, ont été sauvés et réellement lus. Le dessus paraît gris clair sous les grandes sources studio ; le ciel montre le même vinyle sombre teinté de bleu. Les finales96 conservent ces deux cas distincts (quatre vues studio et une entière sous ciel), sans modifier albedo ni balance des blancs.
