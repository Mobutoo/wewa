# Haut moteur — scène de revue liée v1

Ouvrir `upper-engine-current-review-v1.blend` avec le dépôt et ses sept bibliothèques sources dans leurs chemins relatifs. La [revue](../../../creative/reviews/upper-engine-current-review-v1/README.md) donne les images, contrôles et limites.

Le builder existant `tools/build_motorcycle18_assembly_v2.py` est utilisé sans modification ; la commande exacte est conservée dans la revue. Les sources de pièces n'ont pas été sauvegardées ou déplacées. Le GLB `-inspection` conserve l'export initial. Le traitement `-delivery` a constaté zéro référence de tangente inutile : toutes les valeurs JSON et tous les octets BIN sont conservés, sans recalcul de géométrie.

Les repères du haut moteur restent provisoires. Cette réunion de copies sert à examiner les candidats, sans certifier un moteur complet, des cotes OEM, un montage réel ou une réception artistique.
