# Source liée de revue du poste de conduite v3

Le fichier Blender conserve les quatorze bibliothèques de pièces séparées. Seuls les compteurs passent en v5 ; les treize autres sources et les liaisons restent celles de la revue v2. Aucune bibliothèque source n'est sauvegardée ou déplacée par la construction.

Le GLB `cockpit-current-review-v3-delivery.glb` est la livraison contrôlée. L'export brut `cockpit-current-review-v3-inspection.glb` est conservé ; seules ses références de tangentes inutilisées sont retirées pour la livraison, sans mutation des octets binaires.
