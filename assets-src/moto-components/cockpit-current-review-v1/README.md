# Assemblage de revue lié —14 sources

Ouvrir `cockpit-current-review-v1.blend` dans le dépôt complet : ses14bibliothèques Blender sont liées par chemins relatifs. Aucun maillage de pièce original n’est réécrit. Les matrices de repos sont conservées ; seule la copie de poignée RH est parentée au rotor et la copie d’aiguille reçoit un angle de démonstration.

`cockpit-current-review-v1-inspection-v2.glb` est la livraison d’inspection aux tangentes inutilisées retirées. Le fichier sans suffixe`v2` est l’export brut conservé pour diagnostic, avec des tangentes inutiles invalides ; aucune géométrie n’a été corrigée pour masquer les défauts de montage. Le petit faisceau traverse encore le cache central et les gaines hautes/supports restent incomplets.
