Un seul volume positif fermé de tôle ; les deux trous sont des passages dans cette paroi, et non des disques noirs. Pas de congé global après CSG, de remesh, de vis fusionnée ou de support caché. Finition représentative brillante métallique : deux cartes originales 2048² de couleur/rugosité, métal constant1, aucun pixel photographique, normalmap, bump, déplacement ou relief prétendu.
