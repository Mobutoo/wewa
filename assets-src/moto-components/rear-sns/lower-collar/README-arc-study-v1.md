# SNS collar — first observed edge fragment

This is one finite PF-E1 prototype with original analytic sections, one local scalloped free edge and a rounded lip. Angular end caps close the study slice; they are not physical ends. The source is editable, has no modifiers/CSG or private image textures, and exports one static sector.

Three actual Cycles12/OIDN gray/reflection images were saved and opened. Actual GLB21922 triangles pass zero geometric/UV degeneracies and glTF errors/warnings, with minimum face-corner normal dot0.9841. All source edges have valence2 and positive signed volume. The projected-triangle radial clearance lower bound to the authored barrel2 is0.599899mm; this only proves disjoint candidate envelopes in their unplaced coaxial datum, not OEM fit.

E2/E3 and visible upper margin fragments remain unbuilt. Full circumference/count, true section, seat/function and exact currentRDC dimensions are unresolved. Native pixels do not calibrate angles/radii/thickness. The next revision may add the other observed fragments independently; no whole-ring six-notch repetition is implied. This is a partial gray G3 study, without paint or artistic reception.
