This is one approximately regular inner spring. Orange inside black is visible in the related PF122033 photograph and current RDC images; this source initially uses neutral gray. Turn count, hand, diameter, pitch law, endpoint shape and physical size are estimates. The adaptable seller340mm dimensions are not adopted as RDC data.

The source sweeps a circular wire along an editable positive constant-pitch centerline, with analytic radial surface normals and explicit UV. Flat terminal disks are computational closures, not certified ground ends or seat contacts. The exterior spring is separate. No damper, cups, eyes or second shock is included.

Actual geometry checks read the GLB: no zero-area/UV triangles and corner-normal dot above.994. A sampled inter-turn clearance bound and sampled local curvature test are separately reported. These are rest-shape checks, not physical spring rate or compression certification. Three actual Cycles12/OIDN whole/detail/reflection views were opened before this freeze. Fine inner bright traces in the reflective macro are consistent with mutual reflections between nearby coils; they are not modeled grain or measured surface detail.
