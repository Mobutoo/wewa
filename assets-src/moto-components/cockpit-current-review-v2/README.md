# Assemblage de revue lié — révision 2

Ouvrir `cockpit-current-review-v2.blend` dans Blender4.3.2 en conservant les chemins relatifs des quatorze bibliothèques voisines. Ce fichier contient des copies liées de revue ; il ne remplace aucune source de pièce et n’ajoute pas de composant au registre physique.

Seule la bibliothèque de gaines passe en v2 depuis la révision précédente. Treize autres empreintes restent identiques. Les supports isolés ne sont pas placés arbitrairement à l’origine.

Le GLB brut `cockpit-current-review-v2-inspection.glb` est un intermédiaire. Utiliser `cockpit-current-review-v2-delivery.glb` pour la livraison d’inspection, dont seules les références de tangentes inutiles sont retirées, sans modification des octets binaires.
