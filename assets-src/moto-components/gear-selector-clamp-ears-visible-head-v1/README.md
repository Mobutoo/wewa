# JZ561415 — oreilles de bridage et tête extérieure visible

Création Blender originale depuis les poses opposées du même jeu photographique OLX. Les sachets portent JZ561415 ; ce rapprochement ne certifie ni authenticité ni dimensions ni montage RDC125.

Cet enfant contient seulement les deux extensions rectangulaires extérieures du bridage, et la tête hexagonale avec sa portée ronde visible. Le bras, le moyeu annulaire fendu et les caoutchoucs existent déjà : aucun n’est reconstruit ici.

Aucune tige masquée, filetage, écrou arrière, perçage masqué des oreilles ou cannelure n’est fabriqué. La petite trace dorée dans la fente ne permet pas de lire un pas de filetage. L’interface portée ronde/tête n’établit pas si la portée est une embase intégrée ou une rondelle distincte : une seule représentation extérieure est fournie.

Repère provisoire repris du moyeu existant : axe du moyeu Z, fente vers+Y, passage de vis selonX. Les contacts des oreilles suivent le rayon de travail du moyeu existant (13,5 mm) avec un recouvrement de revue de0,25 mm ; ce n’est pas une union ou une certification de montage. Les coupes de fermeture sont techniques, pas des structures internes ajoutées.

Dimensions photographiques estimées et bornées dans la recherche P14 v112. Matières propres proposées : oreilles sombres et tête jaune métallique ; aucun pixel vendeur incorporé en texture. La révision ne vaut pas réception artistique, G8 ou paquet fini.
