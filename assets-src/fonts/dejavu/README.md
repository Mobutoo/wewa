# DejaVu — entrée de typographie originale WEWA

Le fichier TTF fourni est une copie **non modifiée** de DejaVu Sans Condensed Bold Oblique déjà installé pour la création de l’atlas WEWA. Sa [provenance](provenance.json) conserve SHA et octets ; la [notice intégrale](COPYRIGHT.txt) accompagne sa redistribution, autorisée par la licence Bitstream Vera. Les changements DejaVu sont dans le domaine public. Aucun achat, glyphe constructeur ou pixel documentaire n’est ajouté.

La [recette de l’atlas](../../moto-components/fuel-tank-shell/create_original_wewa_atlas.py) attend ce même fichier dans `/usr/share/fonts/truetype/dejavu/DejaVuSansCondensed-BoldOblique.ttf` et la notice système dans `/usr/share/doc/fonts-dejavu-core/copyright`. Pour rejouer cette recette inchangée dans un environnement neuf, fournir ces deux octets aux emplacements attendus et vérifier les empreintes. Le binaire et cette notice permettent cette restauration ; aucune reproduction de l’atlas depuis un clone propre n’est déclarée exécutée ici.

La provenance de l’atlas, créée avant cet ajout, conserve son état historique « binaire non redistribué ». Ce paquet ultérieur fournit désormais la dépendance typographique sans modifier la recette, le PNG existant ou son ancien rapport.
