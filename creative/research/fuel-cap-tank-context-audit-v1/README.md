# Plan de présentation du bouchon — données natives candidates

Le sondage v1 est refusé : il mélangeait des accessoires dont les transformations n’étaient pas évaluées et la peau du réservoir. Son résidu de100mm interdit d’utiliser cette pose.

Le protocole v2 lie réellement les collections, évalue les transformations et échantillonne uniquement la peau du réservoir :64 secteurs du col, résidu maximal0,342mm. Le plan sert à une séparation de revue de2mm ; il n’est ni une mesure physique ni un ajustement du bouchon.

Les dimensions historiques68×47mm du bouchon et56mm d’ouverture intérieure restent incompatibles nominalement en hauteur. Ni matière, ni compression, ni mécanisme intérieur ou joint n’est ajouté pour les faire correspondre. Sources anciennes inchangées, réception G5/G8 absente. Voir native-datums-v1.json (refusé) et native-datums-v2.json (pose de contexte utilisée).
