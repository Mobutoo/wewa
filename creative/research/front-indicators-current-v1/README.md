# Clignotants avant ronds — références liées PF401001/PF401002

Les vraies photos isolées **[PF401001 avant gauche](https://www.croslandrepuestos.pe/direccional-delantero-izquierdo-pf401001/p)** et **[PF401002 avant droit](https://www.croslandrepuestos.pe/direccional-delantero-derecho-pf401002/p)** ont été trouvées chez Crosland et réellement ouvertes. Les RefId sont explicites ; le vendeur annonce BM125/BM150X/BM150XUG. Elles montrent une lentille orange ronde, sa vis supérieure et sa petite encoche inférieure, une coque noire arrondie, une tige à gorges, la fixation métallique et deux fils avec petites cosses.

Cette famille est cohérente avec les rondes orange visibles sur la [page officielle125HD RDC](https://www.bajajauto.com/fr-cd/bikes/boxer-125hd) : `official-headlight.webp` et rotations00/02/04/06 ont été réellement rouverts. **Le numéro exact de la variante RDC actuelle avec USB reste non confirmé.** Aucune photo ne donne de dimensions physiques ou de caméra calibrée.

Les nouveaux originaux sont privés dans `/workspace/wewa-assets/references/front-indicators-current-v1/`. Le [rapport](report.json) donne toutes les URLs, empreintes, angles, variantes et inconnues.

Les quatre fichiers PF ne font que **deux poses**, une par côté. La [photo Matriz DM201027](https://bajajmatriz.com/producto/direccional-delantera-izquierda-boxer-150-y-ct-100-bajaj), réellement ouverte, montre elle aussi une ronde orange. Elle reste une branche vendeur/catalogue distincte, sans supersession PF↔DM établie. Le dessin éclaté en perspective ne certifie pas une lentille physiquement ovale. L’ancien kit générique Sparesgen ovale sans code reste exclu comme exact.

Les deux planches ont été réellement rouvertes. **Aucune ligne de rondelle séparée n’y donne une dimension** : des anneaux figurent dans le dessin, sans norme ni section cotée. M10 ne fournit ni pas, ni largeur sur plats, ni diamètre de bride/rondelle ; ne pas en faire une règle pixel→mm pour la lentille ou la tige. Les tensions/puissances des lampes restent liées aux catalogues anciens, non certifiées pour le matériel actuel.

Le contour de lentille, la petite vis, le rebord, le flanc de coque et la flexion de tige sont désormais mieux documentés pour un candidat extérieur borné. Le **dos isolé, le profil orthogonal complet, le réflecteur/douille internes, les épaisseurs et le montage exact RDC restent inconnus**. Une image Haypo sélectionnée dans une annonce PF401001 était une moto entière ; elle a été ouverte puis écartée comme preuve isolée. Les API Crosland DM201027/28 étaient vides ; aucune absence mondiale n’en est déduite. La recherche s’arrête ici comme convenu avec C.

Aucun pixel constructeur/vendeur n’est publié ou utilisé en texture. Aucun modèle, rendu Blender, source, registre, ancien rapport ou Git modifié.
