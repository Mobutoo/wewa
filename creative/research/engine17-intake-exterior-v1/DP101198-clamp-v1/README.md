# DP101198 — collier, appoint documentaire clos

Une vraie pose isolée attribuée au code exact est disponible chez [Crosland](https://www.croslandrepuestos.pe/abrazareda-id-45-x-w10-dp101198/p). Les deux fichiers 169772/169773 ont été réellement ouverts : même vue oblique, exposition différente, pas deux faces indépendantes. Originaux privés, URLs et SHA dans [report.json](report.json).

La bande métallique est lisse et continue, sans crémaillère ajourée visible. La fermeture comporte deux oreilles relevées, une vis tangentielle et un pont intérieur courbe visible derrière elle. Un candidat extérieur peut maintenant s’appuyer sur ces éléments ; l’écrou captif, la section cachée et l’empreinte exacte de la tête ne sont pas établis. L’aspect jaune irisé ne certifie aucune chimie de traitement.

Le D04 UG5 lie deux DP101198 au manchon PF581402. La fiche Crosland attribue ce code aux Pulsar 135 LS BSIV et Torito 2T ; elle ne certifie pas la variante RDC. « ID 45 X W10 » reste une description commerciale de cette fiche, sans dessin, tolérance ni mesure de la photo. Le résultat de recherche Mintwell « 39 mm » est gardé comme conflit non vérifié, sans moyenne ni transfert. BigBike fournit un intitulé DP101198/92171-1472/CT100 mais aucune image ; aucune supersession constructeur n’est démontrée.

Trois pistes bornées ont été examinées : Crosland, découverte du code exact, BigBike. Recherche arrêtée. Revers indépendant, épaisseur, plage de serrage, filetage et orientation sur la RDC restent inconnus. Aucun modèle ni ancien rapport n’a été modifié ; les pixels demeurent privés et ne sont pas des textures réutilisables.
