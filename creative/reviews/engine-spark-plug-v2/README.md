# Revue bougie v2 — arête de chanfrein reconstruite

Le défaut visible en finale96 de v1 motive une correction locale du corps métallique, avec boucle d’intersection analytique. Les trois autres pièces, matériaux et matrices sont protégés et comparés sur les véritables données exportées.

Les macros natives24 en gris/reflets/PBR doivent être effectivement ouvertes avant le gel. Les nouveaux raccords utilisent head3 et cap69dc sans déplacer leurs sources ni réécrire les preuves historiques cap→plug1. Les sections mécaniques estimées et la matière restent indépendantes de ce correctif de finition.

Toujours une reproduction de l’extérieur installé conditionnel : aucune électrode cachée ou denture/filetage non observables ne sont présentés comme réalisés. Aucune réception utilisateur ou matérielle mobile.
