# Complément de finalisation

Les trois instantanés late-* conservent les derniers ajouts de coordination, intervenus pendant le commit. Le dossier publié initial reste inchangé. Le manifeste late est un instantané historique du working tree de l’agent ; ses chemins sont relatifs au dépôt et ne remplacent pas le manifeste initial. La validation root est conservée dans le supplément documentaire. Aucune forme ni source modifiée, aucune réception.
