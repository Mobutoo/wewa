# Isolant — revue de finition v2

Deux cartes originales de couleur/rugosité, sans normalmap ou relief prétendu. La géométrie v1 reste strictement protégée. Les diagnostics séparent source, triangles exportés, UV/cartes réelles et raccords conditionnels avec head3 et collecteur1.

Les vues de contrôle comprennent une macro neutre et une macro avec lumière rasante. Les photographies restent documentaires privées ; aucune texture de photo n’est produite. G3/cotes, chimie, stries mesurées, faces cachées, interfaces et réception utilisateur demeurent ouverts.
