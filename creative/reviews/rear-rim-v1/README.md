# Jante arrière : candidat extérieur conditionnel

Les deux aperçus PBR et les gris/reflets ont été réellement ouverts avant les finales. Cinq branches sont observées sur les vues RDC ; les sections, largeurs et détails masqués restent estimés. Le centre ouvert est une **enveloppe annulaire partielle**, pas un moyeu complet.

Les vues finales prévues : quarter, reverse, spoke-root-detail et rim-channel-detail, Cycles CPU96/OIDN1200×1100. Les deux macros autorisent explicitement le recadrage. Chaque PNG aura son checkpoint de source, GLB, caméra, lumière et SHA. Les contrôles techniques ne constituent ni réception artistique ni validation sur iPhone.

Les photos attribuées et les cotes conditionnelles sont dans le [README de source](../../../assets-src/moto-components/rear-rim/README.md) et les deux notes de recherche rear-wheel-16. Les preuves runtime produites par root ne sont pas des preuves de fabrication A et seront exclues du manifeste A.
