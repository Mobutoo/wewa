# mirror-left-v2 — preuves du candidat

Deux vrais rendus Cycles 96/OIDN CPU, ensemble et base, ont été ouverts puis relus. Leurs empreintes PNG/EXR et passes albédo/normales sont conservées dans les checkpoints. Le résumé est dérivé des fichiers réellement sauvés, sans rerendu.

La correction aligne le maillage avec le profil hélicoïdal estimé. Neuf autres corps, leurs attributs/indices, matrices, articulation, matières et images sont protégés par comparaison réelle. Les sources précédentes restent immuables. Les cotes et le profil du goujon restent cosmétiques et non qualifiés pour la référence RDC. Aucun contrôle ne vaut réception artistique ou qualification sur iPhone.
