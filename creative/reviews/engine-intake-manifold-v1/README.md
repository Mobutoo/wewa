# Collecteur52JV0180 — revue individuelle conditionnelle

Un seul corps creux de fonderie, sans O-rings, manchon, colliers ou carburateur. Les photographies privées restent documentaires ; aucun pixel de photo n’est dans le matériau. Les dimensions, la face arrière, le petit relief latéral et la finition originale sont explicitement estimés.

Les rapports séparent les étapes géométrie, retessellation bornée, UV/cartes cuites, export réel et interfaces conditionnelles. Les sept premières défaillances natives ont été refusées avant cuisson ; sept rotations locales de diagonale protègent tous les sommets. Les distances de surfaces sont des échantillonnages, pas des mesures OEM.

Les vues gris/reflets/PBR réellement ouvertes seront listées dans preview-review.json avant le préflight ; les finales96 et leurs checkpoints seront closes ensuite par record_review.py. Aucune réception artistique ou matérielle iPhone n’est acquise.
