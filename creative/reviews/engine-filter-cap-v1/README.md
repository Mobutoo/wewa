# Bouchon de filtre seul — candidat v1

Les vues isolées montrent la face à anneau et les oreilles puis l’emmanchement creux arrière. Les rendus définitifs Cycles96/OIDN possèdent chacun un checkpoint source/configuration/PNG/EXR indépendant. Les captures Babylon du coordinateur sont liées séparément.

Trois oreilles viennent du catalogue voisin ; leur conformité au modèle RDC reste ouverte. Profondeurs, épaisseurs, diamètres, entraxes, orientations et jeux sont estimés. Les vis, le filtre et le joint sont absents. Le contrôle de surfaces contre le carter figé ne prouve pas les filetages réels correspondants, l’étanchéité ou un montage mécanique certifié.

Une géométrie fermée, un export valide et une vue propre ne constituent pas une réception de fidélité ou de matière. Aucun accord artistique utilisateur ni essai iPhone physique acquis.
