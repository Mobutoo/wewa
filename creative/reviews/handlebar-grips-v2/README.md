# Poignées v2 — preuve candidate

Correction de côté : gauche physique +X, droite physique −X dans le repère du cockpit. La v1 n’a pas été réécrite.

`left-quarter.png` et `right-quarter.png` sont deux rendus Blender réels du fichier v2, 1100 × 850, Cycles 96 échantillons, OIDN. Chaque vue masque l’autre poignée. Le rapport de source contrôle deux volumes fermés, connexes et positifs ; le contrôle GLB examine les buffers, le matériau et la carte originale de rugosité. Ces contrôles ne certifient pas le motif, le matériau observé ou la variante RDC.

La lecture interne constate un profil continu, les canaux géométriques et la collerette, sans prétendre à une superposition mesurée avec les photographies de vendeur. Le dessus gris sous le studio appelle une comparaison photographique mieux étalonnée avant réception de matière. Le compte des canaux et les sections invisibles restent estimés.

Les captures `engine-*` et `export-buffer-check.json` sont produites séparément par le coordinateur ; le manifeste local de fabrication ne les inclut pas afin de ne pas figer leurs révisions en cours. Aucun de ces fichiers ne vaut réception utilisateur ou essai physique iPhone.
